# API de Productos con NestJS y Prisma

Este proyecto es una API REST para la gestión de productos, construida con NestJS, Prisma y una base de datos relacional (SQLite por defecto, pero fácilmente adaptable a PostgreSQL o MySQL).

## Requisitos

- Node.js >= 18.x
- npm o yarn
- Docker (opcional, si usas bases de datos externas)
- Prisma CLI

## Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/juandavid08/api-productos.git
cd api-productos
```
